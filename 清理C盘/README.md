# C盘一键清理工具

这里提供了两种清理C盘的方案：

## 方案一：图形化清理程序 (推荐 Python 用户)
拥有可视化界面，操作更直观，更安全。

### 使用方法：
1.  确保电脑已安装 [Python](https://www.python.org/downloads/)。
2.  **推荐方式**：双击运行 `run_app.bat`。
    *   它会自动检测您电脑上是 `python` 还是 `py` 命令，并启动程序。
    *   这也是解决 "无法将 python 识别为 cmdlet" 错误的最简单方法。
3.  程序会自动请求管理员权限。
4.  点击“开始扫描”查看垃圾文件大小。
5.  点击“立即清理”执行删除。

### 文件说明：
*   `main.py`: 程序入口。
*   `ui.py`: 界面代码。
*   `cleaner_core.py`: 核心清理逻辑。

---

## 方案二：一键清理脚本 (无须安装)
如果没安装Python，可以直接使用批处理脚本。

### 使用方法：
1.  右键点击 `clean_script.bat`。
2.  选择“以管理员身份运行” (虽然脚本会自动请求，但手动更稳)。
3.  等待黑窗口执行完毕即可。

### 清理范围：
*   Windows 系统临时文件
*   用户临时文件 (AppData/Temp)
*   预读取文件 (Prefetch)
*   回收站
