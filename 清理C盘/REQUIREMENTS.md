# C盘一键清理工具 - 需求分析与设计文档

## 1. 项目背景
开发一个简单易用的Windows桌面程序，旨在帮助用户“一键”扫描并清理C盘中的垃圾文件，释放磁盘空间。

## 2. 功能需求

### 2.1 核心功能
1.  **一键扫描**：
    *   自动识别常见的系统垃圾路径。
    *   计算可释放的总空间大小。
    *   展示垃圾文件列表（可选）。
2.  **一键清理**：
    *   删除扫描出的垃圾文件。
    *   跳过正在使用的文件（避免程序崩溃）。
    *   清理完成后反馈释放空间结果。
3.  **权限管理**：
    *   程序需要以**管理员身份**运行，以便清理 `C:\Windows\Temp` 等系统目录。

### 2.2 清理目标 (Target Scope)
程序将主要针对以下安全目录进行清理：
1.  **用户临时文件夹**: `%TEMP%` (即 `C:\Users\Username\AppData\Local\Temp`)
2.  **系统临时文件夹**: `C:\Windows\Temp`
3.  **预读取文件 (Prefetch)**: `C:\Windows\Prefetch` (不仅释放空间，有时能解决系统卡顿)
4.  **Windows更新缓存**: `C:\Windows\SoftwareDistribution\Download` (通常占用巨大)
5.  **系统日志**: `C:\Windows\Logs`
6.  **回收站**: Empty Recycle Bin

### 2.3 非功能需求
*   **安全性**：绝不能误删用户文档、桌面文件或关键系统组件。
*   **稳定性**：遇到被占用的文件应静默跳过，记录日志但不报错中断。
*   **易用性**：界面简洁，最好只有“扫描”和“清理”两个主按钮。

## 3. 技术选型
*   **语言**: Python 3.x
    *   原因：拥有强大的 `os` 和 `shutil` 库进行文件操作，且开发效率高。
*   **GUI框架**: Tkinter
    *   原因：Python内置，无需额外安装庞大的依赖库，生成的exe体积相对较小，足以应付简单工具界面。
*   **打包工具**: PyInstaller
    *   原因：最终将脚本打包成 `.exe` 文件，方便用户直接运行。

## 4. 架构设计
*   `cleaner_core.py`: 负责底层的扫描和删除逻辑，不含UI代码。
*   `gui.py`: 负责界面展示，调用核心逻辑，处理多线程（避免界面卡死）。
*   `main.py`: 程序入口。

## 5. 风险与对策
*   **风险**: 文件正在被其他程序使用，无法删除。
    *   **对策**: 使用 `try...except` 捕获 `PermissionError` 和 `OSError`，跳过该文件。
*   **风险**: 误删重要文件。
    *   **对策**: 严格限定扫描目录，不进行全盘模糊搜索，只针对特定路径操作。
